# BookNook – A Small Online Library
**Live site:** https://your-booknook.vercel.app  (replace after deploying)

## Features
- Add, edit and delete your own books (cover upload via imgbb)
- Borrow a book with copy tracking ($inc) and no double-borrowing
- Return books from a personal My Borrows table
- BetterAuth login with email/password and Google, plus protected private routes that survive reload
- Swiper home slider, latest-6 New Arrivals, dark/light theme and responsive layout
- JWT-protected Express API

Setup: copy `.env.example` to `.env.local`, fill values, `npm i && npm run dev`.
- Search books by title or author; AOS scroll animations
